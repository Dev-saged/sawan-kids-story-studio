# عامل Colab لتحريك صفحات القصة

`sawan_worker.py` هو المصدر الوحيد للكود، ويُنسخ إلى الدفتر عبر `python3 scripts/build-colab-notebook.py` (يولّد `sawan_video_worker.ipynb`).

- النموذج الافتراضي `wan-ti2v-5b` (Wan 2.2، Apache-2.0): 720p بـ24 إطاراً في الثانية، مقطع ≈ 5 ثوانٍ.
- `wan-i2v-a14b` أعلى جودة وأبطأ بكثير (480p، 16 إطاراً في الثانية)، ويحتاج ذاكرة GPU كبيرة.
- كود النموذج لم يُختبر على GPU حقيقي في بيئة التطوير؛ منطق الطابور والحلقة مختبر بنموذج وهمي (`test_worker.py`). إن فشل تحميل النموذج فالخطأ يظهر في خلية التشغيل، وأي فشل أثناء مهمة يصل للتطبيق برسالته.
- شروط Colab: لا خادم ولا نفق هنا؛ العامل يسحب المهام فقط. الجلسة قد تنقطع (خمول أو 12 ساعة)، فأعد تشغيل الخلية الأخيرة.

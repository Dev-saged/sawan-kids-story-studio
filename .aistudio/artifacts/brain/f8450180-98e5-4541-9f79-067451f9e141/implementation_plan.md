# خطة الترقية الشاملة واستقرار الاستوديو v2.3.0 (Studio Upgrade & Stabilization)

ترقية تطبيق صوان لاستوديو القصص إلى الإصدار **v2.3.0**، مع ميزة استنساخ الصوت الذكي التلقائي، والقضاء الجذري على الأخطاء التقنية المتبقية (Maximum update depth exceeded وتنبيهات الحصة)، وتوفير منظومة خطوط غلاف فاخرة، وقصص فواكه درامية لليافعين (12-18 سنة)، ودعم تحريك الفيديو السينمائي عبر Veo 3.

---

## مراجعة المستخدم والقرارات المؤكدة (User Review & Confirmed Choices)

> [!IMPORTANT]
> تم تحديث الخطة لإضافة ميزة **استنساخ الصوت الذكي (Voice Cloning & AI Narrator)** بحيث يكفي أن تسجل مقطعاً صوتياً قصيراً بصوتك لمرة واحدة فقط، ليقوم النظام بتحليله وحفظ بصمته الصوتية، ثم توليد قراءة كامل القصة بصوتك آلياً دون الحاجة لقراءة كل صفحة يدوياً!

- **استنساخ الصوت الذكي (One-Shot Voice Profile)**: تسجيل عينة صوتية واحدة (10-15 ثانية)، تحليل النبرة ونطاق التردد والوتيرة، وتوليد تلاوة القصة كاملة بصوتك المحاكي.
- **خط الغلاف المعتمد**: الخط الكوفي الهندسي الحديث الفخم (Modern Bold Geometric Arabic Kufi) كنمط افتراضي، مع مبدّل فوري لـ 4 أساليب خطية ملكية (كوفي، ديواني وثُلث، نسخ ورقعة قصصي، وثلاثي أبعاد بارز).
- **قصص الفواكه لليافعين (12-18 سنة)**: تضمين **كافة الخيارات الأربعة** المقترحة مع إمكانية التبديل بينها (صراع الممالك الفانتازي، عالم السايبربانك التقني، مغامرة البقاء البرية، والدراما الفلسفية العميقة).
- **تحريك Veo 3 في تصدير الفيديو**: تضمين **كافة الأنماط الثلاثة** (المؤثرات السينمائية الكاملة، الحركة البارالاكسية 2.5D مع سكريبت Veo، ومسح الكاميرا ثلاثي الأبعاد مع إعدادات حركة الشخصيات).

## 1. نظرة عامة والميزات الجديدة (Overview & Core Features)

1. **استنساخ الصوت الذكي وتلاوة القصة آلياً (Smart Voice Cloning & Auto-Narration)**:
   - واجهة جديدة في قارئ القصة وقسم العائلة: **«استنسخ صوتك ليروي القصة»**.
   - يقوم الوالد/الوالدة بقراءة عبارة قصيرة واحدة (10-15 ثانية).
   - يقوم النظام عبر Web Audio API وتحليل الطيف الصوتي (Pitch, Timbre, Cadence, Spectral Energy) باستخراج البصمة الصوتية وحفظها في `IndexedDB` كملف صوتي دائم باسم المستخدِم.
   - عند الضغط على «قراءة بصوتي»، يتولى النظام قراءة نص القصة تلقائياً بنفس النبرة والإيقاع الصوتي المحفوظ دون إجهاد الوالدين.
2. **الترقية التلقائية للإصدار (v2.3.0)**:
   - مزامنة وتحديث رقم الإصدار في `package.json` و`src/config.ts`.
3. **الحل الجذري لخطأ التكرار اللانهائي في React (`Maximum update depth exceeded`)**:
   - تثبيت snapshot مرجعي في `ErrorDetails.tsx` وتفادي إنشاء مصفوفات جديدة في كل استدعاء لـ `useSyncExternalStore`.
4. **معالجة تنبيهات الحصة وتوليد الصور بأعلى الشاشة (Quota Exceeded & Image Generation)**:
   - كتم شريط الأخطاء الأحمر العام بأعلى الشاشة واستبداله بحالة تقدم هادئة محلية وتراجع أسي ذكي.
5. **تطوير خط غلاف الكتاب (Luxury Cover Typography)**:
   - خط كوفي هندسي فخم، ديواني ملكي، نسخ ورقعة، وثلاثي أبعاد مع مبدّل مباشر.
6. **قصص الفواكه الدرامية لليافعين (12-18 سنة - Teens / Young Adults)**:
   - فئة عمرية `13-18` مع 4 عوالم درامية للفواكه ومفاجآت ذكية متكيفة.
7. **تصدير الفيديو السينمائي وحركات Veo 3**:
   - الأنماط السينمائية الثلاثة لـ Veo 3 داخل `VideoExportSheet.tsx`.

## 3. المعمارية التقنية واستراتيجية البيانات (Technical Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Voice Cloning Pipeline                          │
├────────────────────────────────────────────────────────────────────────┤
│  User Audio Sample (10-15s)                                            │
│        │                                                               │
│        ▼                                                               │
│  AudioContext Spectral Analyzer (Pitch, Formants, Energy Profile)      │
│        │                                                               │
│        ▼                                                               │
│  Cloned Voice Profile Saved to IndexedDB (`voice-profiles`)            │
│        │                                                               │
│        ▼                                                               │
│  Auto-TTS Synthesis (synthesizes page narration matching pitch/timbre) │
│        │                                                               │
│        ▼                                                               │
│  Karaoke-Synced Playback on Reader with zero manual reading needed     │
└────────────────────────────────────────────────────────────────────────┘
```

1. **خدمة استنساخ الصوت (`src/services/voiceClone.ts`)**:
   - `recordVoiceSample()`: التقاط عينة صوتية نظيفة.
   - `analyzeVoiceProfile(blob)`: استخراج التردد الأساسي والمتوسط النغمي.
   - `synthesizeClonedNarration(text, profile)`: قراءة النص آلياً ومواءمته مع بصمة الصوت.
2. **تخزين وإدارة الملفات (`src/services/library.ts` & `db.ts`)**:
   - جدول `voice_profiles` لحفظ العينات والبصمات عبر الجلسات.
3. **تكامل قارئ القصة (`useNarration.ts` & `StoryReader.tsx`)**:
   - إضافة خيار `'ClonedVoice'` في قائمة الأصوات.
   - تشغيل وتوليد الصفحات آلياً بالصوت المستنسخ دون توقف.
